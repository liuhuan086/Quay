# Quay Privacy Policy

Effective date: 2026-05-19

Quay is a macOS FTP, FTPS, and SFTP client. The app is designed to keep connection data on your Mac and does not collect analytics, advertising identifiers, or tracking data.

## Data Stored Locally

Quay stores server profiles, sync rules, preferences, and SFTP known-host fingerprints locally on your Mac. Server passwords are stored in the macOS Keychain. SSH private-key file access is stored as a macOS security-scoped bookmark so the app can read the selected key after restart.

## Network Connections

When you connect to a server, Quay sends the connection details and credentials you provide directly to that server using the selected protocol. Quay does not proxy your traffic through a third-party service.

## Data Collection

Quay does not collect, sell, rent, or share personal data. If you install the app from the Mac App Store, Apple may process purchase, crash, and diagnostic information according to Apple's own policies.
